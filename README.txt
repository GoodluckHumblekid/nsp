NGASA SHADRACK PORTFOLIO — CPANEL INSTALLATION

1. Extract this ZIP on your computer or phone.
2. Open cPanel > File Manager > public_html.
3. Upload index.html, style.css and script.js (or upload the ZIP and use Extract).
4. Visit your domain to view the portfolio.

CUSTOMISE:
- Edit index.html to update the biography, education, services, email, phone and project cards.
- Replace the concept project visuals with screenshots/photos of your real work.
- To add a profile photo, upload it to assets/ and edit the hero section in index.html.
- Update WhatsApp number in the link https://wa.me/255744942610 if necessary.

NOTES:
- This is a static responsive website; no database or PHP is required.
- The contact buttons open the visitor's email app or WhatsApp.
- Google Fonts requires an internet connection; system fallbacks are included.
